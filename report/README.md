# AI 眼中的你 · 互动报告

《板材上下游 AI 推荐观察白皮书 2026》的互动附录：把美国网络基线的 120 条 AI 回答做成一部 3D 星图影片（8 个场景）和 12 页报告，最后一页是体检入口。

在线打开：https://mix-shijie.github.io/geo-whitepaper/report/

- **只含聚合统计**。没有 AI 回答原文、引用标题和链接；品牌名按审核表部分隐去；城市内的门店只有编号；不含测试人信息。
- **真实数据只看行业总览**。单品牌视图只给虚构的演示品牌"江南*澜木业"（名字是虚构的，和真实品牌无关），页面标"虚构示例"。
- **不带任何配音文件**。影片默认静音、显示中文字幕；点"朗读"用浏览器自带的语音念英文解说，点"音乐"打开页面里程序生成的底乐和音效。
- 方法、口径与完整统计见[白皮书](../whitepaper.md)。统计的是 AI 回答中的出现情况，不代表产品质量、企业规模或市场份额。

数据与文字采用 CC BY 4.0，代码采用 MIT（见仓库根目录）；three.js r147 为 MIT 许可，见 `vendor/three/LICENSE`。

常用参数：`#report` 直接进报告，`?page=10` 第几页，`?dataset=us|cn|mix` 数据集，`?subject=demo` 虚构示例，`?vertical` / `?horizontal` 竖屏 / 横屏，`?print` 打印版。
